PagodaPDF

Private PDF tools for everyday work

PagodaPDF is a browser-based PDF toolkit focused on useful document actions without forcing your files through an upload-first workflow. It is being adapted as an open source project with a lighter, cleaner interface.

Local First

Core PDF actions run in the browser whenever possible, keeping documents on your device.

Open Source

The source can be reviewed, modified, and shared under the AGPL-3.0 license.

Practical

The interface is built around getting to the right PDF tool quickly.
