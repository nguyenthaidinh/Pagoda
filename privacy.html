Privacy Policy

Last updated: September 2, 2026

Local Processing

PagodaPDF is designed so ordinary PDF operations happen inside your browser. Your selected files are not uploaded to a PagodaPDF server for those operations.

Network Requests

Some advanced features may request public runtime assets such as WASM modules, OCR files, fonts, or timestamp authority endpoints depending on your build configuration.

No Account Requirement

The current static app does not require an account, login, or database-backed user profile.

Open Source

Because the project is open source, you can inspect the source code and deployment configuration used by your copy of PagodaPDF.
