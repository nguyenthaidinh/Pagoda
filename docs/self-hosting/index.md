# Self-Hosting PagodaPDF

Build PagodaPDF from this repository so the deployed files match the public
source. No official PagodaPDF container registry is currently published.

## Static build

```bash
npm ci
npm run build
```

Serve the contents of `dist/` with a static web server. Preserve the security
headers generated by the build, especially COOP and COEP for Office conversions.

For GitHub Pages at this repository's default URL:

```bash
SITE_URL=https://nguyenthaidinh.github.io/Pagoda BASE_URL=/Pagoda/ npm run build
```

On Windows PowerShell:

```powershell
$env:SITE_URL='https://nguyenthaidinh.github.io/Pagoda'
$env:BASE_URL='/Pagoda/'
npm.cmd run build
```

## Docker

The included `docker-compose.yml` builds the current source locally:

```bash
docker compose up --build -d
```

Open `http://localhost:3000`. For access from another device, put the service
behind HTTPS; a plain LAN IP is not a secure browser context.

See [Docker deployment](/self-hosting/docker) for image commands and runtime
checks.

## Runtime assets

Several advanced tools use WebAssembly, OCR workers, language data, or fonts.
Review `.env.example` and the generated Content Security Policy before replacing
their URLs. For an offline deployment, host every required asset yourself and
verify the tools without network access.
