# Pagoda
PagodaPDF — Bộ công cụ PDF miễn phí, ưu tiên quyền riêng tư và xử lý trực tiếp trên trình duyệt. Dựa trên BentoPDF và phát hành theo AGPL-3.0.

[BentoPDF](https://github.com/alam00000/bentopdf).
